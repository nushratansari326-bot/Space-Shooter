# Space Shooter Game

## Project Information
- **PS No.:** 59
- **Project Title:** Space Shooter
- **Language:** Python 3
- **Library:** Pygame

## Project Description
Space Shooter is a 2D shooting game developed using Python and Pygame.

The player controls a spaceship at the bottom of the screen and shoots bullets to destroy incoming enemies.

## Features
1. Spaceship movement using LEFT and RIGHT arrow keys.
2. Shooting bullets using SPACE key.
3. Maximum 5 bullets on screen.
4. Enemy generation and movement.
5. Collision detection.
6. Score increases by 10 for every enemy destroyed.
7. Three lives system.
8. Game Over screen and restart option.

## Controls
- LEFT Arrow: Move left
- RIGHT Arrow: Move right
- SPACE: Fire bullets
- R: Restart game
- ESC: Exit game

## Installation

```bash
pip install pygame
```

## Run the Project

```bash
python main.py
```
